# Mitwirken

Arbeitsraum ist ein lokales macOS-Projekt. Fehlerberichte, Ideen und Verbesserungen können über die GitHub-Issue-Vorlagen eingereicht werden. Das Einreichen von Feedback auf GitHub benötigt eine Internetverbindung; die Kernfunktionen von Arbeitsraum sind für die Offline-Nutzung vorgesehen.

Bitte veröffentliche niemals Patienten-, Schüler- oder Kundendaten oder echte Dokumente. Verwende in Beispielen ausschließlich erfundene oder vollständig anonymisierte Inhalte. Füge keine Logs oder Dateien an; es gibt keine automatisch angehängten Logs oder Uploads.

## Lokal bauen

Voraussetzung ist eine passende Xcode-Installation. Im Projektverzeichnis:

```sh
./build.sh
```

Für Änderungen bitte mit synthetischen Beispieldaten arbeiten. Reiche Änderungen als Pull Request mit einer kurzen Beschreibung des Anlasses und der sichtbaren Auswirkungen ein. Vermeide Zugangsdaten und vertrauliche Inhalte in Quelltext, Screenshots, Beispieldaten und Commit-Nachrichten.
